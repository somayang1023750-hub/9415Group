# Member A presentation

Five English slides for an approximately three-minute presentation:

1. Day and Night overview (two screenshots; no framework diagram).
2. Gameplay and progression.
3. Three enemy types and pursuit.
4. Bullet and Laser impact effects.
5. Bomb blast and rotating ground fire.

## Files

- [PowerPoint](Member_A_Presentation.pptx) — editable slides with the script in speaker notes.
- [PDF](Member_A_Presentation.pdf) — presentation fallback.
- [Word script](Member_A_Script.docx).
- [Plain-text script](Member_A_Script.txt) — readable directly on GitHub.

Open a file on GitHub and use **Download raw file** to save it. After pulling the repository, the files are also available directly in this directory.

The script is approximately 290 words. Its opening explains Day/Night enemy releases and final generation weights, distinct from living population quotas.

## Images

The overview uses the production Day and Night layouts and lighting, captured with stationary staged actors. Gameplay/progression and model images come from the contributor's final report. Impact and fire close-ups use the production ArenaScene and ParticleEffects renderer. The small orbit illustration is an explanatory diagram.
